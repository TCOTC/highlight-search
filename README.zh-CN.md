# 文档高亮搜索

在当前打开的文档内查找文本，并高亮全部命中；支持跳转上一项 / 下一项，以及替换当前匹配文本。

## 打开方式

- 点击顶栏右侧按钮
- 默认快捷键 `Ctrl+Shift+Alt+F` / `⌥⇧⌘F`：打开搜索
- 默认快捷键 `Ctrl+Shift+Alt+R` / `⌥⇧⌘R`：打开搜索替换
- 以上快捷键均可在「快捷键」设置中修改

还可为「上一项」「下一项」「替换当前」自行绑定快捷键。

## 功能

- 搜索时区分大小写、全词匹配
- 结果列表面板，按文档阅读顺序浏览命中
- 替换当前匹配文本，可选保留大小写
- 全部替换请继续使用思源官方 `Ctrl+R` / `⌘R`

## 范围说明

只搜索当前页签文档正文，不含界面文案与文档标题。替换仅作用于白名单内的可见文本（如普通段落、列表项等），公式、图表等不可替换上下文会禁用替换按钮。
