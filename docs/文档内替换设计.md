# 文档内替换设计

在当前打开的文档里做「替换当前」一处匹配。交互对齐 VS Code find widget 的替换行；**不做全部替换**（交给思源官方 `⌘R`）。

与查找的关系见 [文档内搜索设计.md](./文档内搜索设计.md)。查找仍按可见文本建 Match；替换仅在白名单上下文中改 DOM 文本并写回块。

## 范围

| 做 | 不做 |
|----|------|
| 替换当前匹配（occ 级） | 全部替换 |
| 白名单块 / 行内可见文本 | 公式、图表 SVG、`data-content` 回退命中 |
| 保留大小写（VS Code 简单算法） | replaceTypes 过滤、正则替换 |
| `block-ref` 改锚文本并 `d`→`s` | 嵌入块内部、文档标题 |

当前匹配不在白名单时：**禁用**「替换」按钮（快捷键也不强行替换）。

## 流程

```text
当前 Match
    │
    ▼
isReplaceable（块类型 ∩ 行内 token ∩ 硬条件 ∩ DomHit）
    │
    ├─ 否 → 按钮禁用
    └─ 是 → 可选 Preserve Case 变换替换串
              │
              ▼
         改 Range 文本（block-ref 先 data-subtype=s）
              │
              ▼
         updateBlock(dom) 写回该块
              │
              ▼
         FindSession.rebuild，尽量停在下一处
```

## 白名单 A：叶子块 `data-type`

| `data-type` | 条件 |
|-------------|------|
| `NodeParagraph` | 无 |
| `NodeHeading` | 无（`h1`–`h6`） |
| `NodeCodeBlock` | 有 `code-block` 且 **不是** `render-node` |
| `NodeTable` | 命中在表内 `th`/`td` 可编辑文本 |

`NodeTable` 是叶子块：单元格为行级 `th`/`td`，无嵌套 `data-node-id` 子块；Match 的 `blockId` 即表格 ID，写回整表。

列表 / 引述 / Callout / 超级块是容器，命中落在其内白名单子块上。

## 白名单 B：行内 `data-type` token

纯文本，或祖先 `span[data-type]` 的 token **仅**属于：

`text`、`strong`、`em`、`u`、`s`、`mark`、`sup`、`sub`、`kbd`、`code`、`a`、`block-ref`、`file-annotation-ref`、`inline-memo`、`tag`、`virtual-block-ref`

- `a` / `block-ref` / `file-annotation-ref`：只改锚文本，不改 `data-href` / `data-id` 等
- `inline-memo`：只改外侧可见字，不改 `data-inline-memo-content`
- `tag`：只改可见字，保持标签类型
- `block-ref`：替换前将 `data-subtype` 设为 `s`（动态→静态，对齐思源）
- `virtual-block-ref`：按普通可见文本替换；思源写回时不当作真实引用持久化

## 硬条件

- 不在 `svg` / `.katex` / `.katex-html` / `.katex-mathml` 内
- 不在嵌入块 `NodeBlockQueryEmbed` 祖先下（投影视图，写回易改错源块）
- Match 不是 `fromDataContent` 回退
- 能在当前编辑器解析到该 occ 的 DOM Range

## 明确排除（摘要）

块：`render-node` 代码/图表、`NodeMathBlock`、`NodeHTMLBlock`、嵌入 / 数据库 / 媒体 / 容器本体 / 文档根等。  
行内：`inline-math`、`img`、备注气泡正文等。

嵌入禁用原因：内层段落仍带**源块** `data-node-id`，`updateBlock` 可能改到其它文档；同一 ID 可多处出现；嵌入会重渲染。

## 保留大小写

对齐 VS Code `buildReplaceStringWithCasePreserved`，**不做**驼峰分词：

1. 匹配与替换串都含 `-`（或都含 `_`）且段数相同 → 按段套规则再拼回  
2. 否则：全大写 / 全小写 / 首字母大写或小写微调；无法识别则原样用替换串  

默认关闭；搜索框实例独立，不持久化。

## 写回

优先改活 DOM 上当前 Range 的文本，再 `POST /api/block/updateBlock`（`dataType: "dom"`）。成功后重建 Match 列表与高亮。
